\# 📊 Job Market Intelligence Dashboard



A Python-based data analytics project that explores technology job-market trends, salary information, in-demand skills, locations, and experience requirements.



\## 🚀 Features

\- Interactive dashboard built with Streamlit

\- Job-market overview and key metrics

\- Average disclosed salary analysis

\- Most in-demand technical skills

\- Job-location filtering

\- Salary and experience filters

\- Searchable job listings

\- Skill gap analysis



\## 🛠️ Tech Stack

\- Python

\- Pandas

\- NumPy

\- Matplotlib / Seaborn

\- Streamlit

\- Git \& GitHub



\## 📂 Dataset

The project analyzes job-posting data containing job titles, companies, locations, salaries, experience requirements, and skills.



\## ▶️ Run Locally



```bash

pip install -r requirements.txt

streamlit run dashboard/app.py

```



\## 🎯 Objective

To turn job-posting data into actionable insights that help users understand hiring trends, salary patterns, and in-demand technical skills.
